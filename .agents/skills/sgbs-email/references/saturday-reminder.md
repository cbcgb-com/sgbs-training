# Saturday homework reminder

A short reply on last week's homework thread. Body and subject come
from `compose_homework_reminder_email()` and
`homework_reminder_subject(upcoming_class_number)`. Do not paraphrase
or extend them.

Draft only, from Eric's HEY account. See
[../SKILL.md](../SKILL.md) and
[common-mistakes.md](common-mistakes.md).

If this file and the code disagree, the code wins.

## Body (must match the function)

溫馨提醒！請大家把功課做好喔！鏈接在之前的郵件裡。

也請大家準時。3點開始！

Two lines, one blank line between them, nothing else. No homework
list, no Google Doc or site links, no greeting, no 主內 sign-off.

## Subject

`小組查經帶領訓練課堂「N」功課提醒` — N is the **upcoming**
class (tomorrow). Example: `小組查經帶領訓練課堂「5」功課提醒` for the
2026-10-18 class.

## Procedure

1. Find last week's homework email (subject
   `小組查經帶領訓練課堂「N-1」功課`) and reply on **that** thread.
2. From Eric's HEY account. Keep that thread's To/Cc. Do not add or drop
   anyone.
3. Draft only, then tell Eric it is ready.
4. Do not append extra text.

Served at `/homework-reminder-email` ("Get Homework Reminder Email").
